# UI_SPEC — 桌面伴侣表情动画设计规范

> 本文件定义 7 个状态的表情动画。配套有一个 HTML 预览原型文件，
> **动画的最终视觉效果以 HTML 预览为准**，本文件是它的文字化规范，
> 供 Claude Code 在 LVGL 中复现。

## 屏幕与画布

- 物理屏幕：368 × 448 像素，AMOLED，长方形竖屏。
- 背景：**纯黑 `0x000000`**。AMOLED 纯黑不发光，省电，且让表情像浮在屏上。
- 所有表情元素居中布局，整张脸在画面中上部，下方留给嘴 / 状态文字。

## 脸的构成部件

一张脸由以下 LVGL 对象组成（全部用矢量图形，不用图片序列帧）：

| 部件 | 数量 | LVGL 实现建议 | 说明 |
|------|------|--------------|------|
| 眼睛 | 2 | 圆角矩形 `lv_obj` | 默认形态。可缩放（眨眼=纵向压扁）|
| 眼睛高光 | 2 | 小白色圆点 | 叠在眼睛左上，增加灵气 |
| 眉毛 | 2 | 圆角矩形（细长） | 默认隐藏，部分状态显示并旋转 |
| 嘴巴 | 1 | 圆角矩形 / 圆弧 | 默认隐藏，部分状态显示 |
| 笑眼 | 2 | 圆弧（上半圆 ∩） | done 状态时替换普通眼睛 |
| 叉叉眼 | 2 | 两条交叉短线 ╳ | error 状态时替换普通眼睛 |
| 进度环 | 1 | `lv_arc` | working 状态时显示，绕脸一圈 |
| 思考点 | 3 | 3 个小圆点 | thinking 状态时显示并跳动 |
| 光晕 | 1 | 径向渐变 / 半透明圆 | 脸背后的氛围光，颜色随状态变 |
| 星星 | 若干 | 小圆点 | done 状态时四周闪烁 |

> 每个状态有一个主题色，光晕、眼睛发光、文字都用这个色。

## 全局动画

- **漂浮**：整张脸缓慢上下浮动（约 5 秒一个来回），让它"活着"。
  error 状态例外（脸是耷拉静止的）。

## 7 个状态规格

### 1. idle 待命
- 主题色：冷白 `#cdd6f4`
- 眼睛：正常圆角矩形，**慢眨眼**（约每 5 秒眨一次，眨眼=纵向迅速压扁再弹回）
- 眉毛 / 嘴：隐藏
- 光晕：很弱（约 14% 透明度）
- 整体：安静、放松、有呼吸感

### 2. thinking 思考中
- 主题色：青色 `#7dd3fc`
- 眼睛：正常，**左右来回看**（整张脸水平小幅平移，约 3 秒一来回），仍会眨眼
- 眉毛：显示，微微内八（左眉逆时针、右眉顺时针小角度），呈思考状
- 思考点：脸下方 3 个点依次跳动（像打字 / 省略号）
- 光晕：中等
- 状态文字（可选）：`thinking…`

### 3. working 执行任务
- 主题色：蓝色 `#5b9dff`
- 眼睛：压扁成专注的细线条（高度约 60%），轻微横向脉动
- 进度环：绕脸一圈的圆弧，**持续旋转扫动**
- 光晕：脉动（明暗交替，约 1.4 秒周期）
- 状态文字（可选）：`running…` / 当前工具名

### 4. waiting 等待用户确认
- 主题色：琥珀 `#f5b53d`
- 眼睛：**瞪大**（放大约 1.16 倍），仍眨眼
- 眉毛：显示，挑起（外八，呈"期待 / 着急"状）
- 嘴巴：显示，**一张一合**（像在喊你）
- 整体：**整张脸左右晃动**（轻微摇摆，引起注意）
- 光晕：较强且快速脉动
- 提示音：进入该状态时播放（见下方"提示音"）
- 状态文字（可选）：`awaiting input`
- 这是**最需要吸引注意**的状态，动画要明显。

### 5. speaking 说话（第一步预留）
- 主题色：紫色 `#c08bf0`
- 眼睛：正常偏放松
- 嘴巴：显示，**快速开合**模拟说话口型
- 光晕：快速轻脉动
- 说明：第一步 UI 要实现这个状态，但不会被触发；
  留给第二步接入 TTS 语音播报时使用。

### 6. done 任务完成
- 主题色：绿色 `#46d68a`
- 眼睛：替换为**笑眼**（上半圆弧 ∩∩），进入时有一个"弹出"动画
- 嘴巴：显示，**咧嘴笑**（向下凸的圆弧），进入时横向展开
- 星星：四周若干星星闪烁一阵
- 光晕：进入时较亮，然后回落
- 提示音：进入该状态时播放成功音
- 状态文字（可选）：`completed`

### 7. error 出错
- 主题色：红色 `#f06a5e`
- 眼睛：替换为**叉叉眼**（╳╳），进入时有"砸下来"的动画
- 眉毛：显示，八字下垂（沮丧）
- 嘴巴：显示，嘴角下垂（向上凸的小圆弧）
- 整体：**脸向下耷拉并轻微歪斜**，不漂浮（静止）
- 光晕：中等
- 提示音：进入该状态时播放错误音
- 状态文字（可选）：`error` / exit code

## 状态切换

- 状态之间切换时，做一个短暂（约 0.2~0.3 秒）的过渡，不要硬切。
- 切换由外部指令驱动（WiFi 收到的 state 值）。

## 提示音（第一步：简单音效，非人声）

用板载扬声器（ES8311 驱动）播放简单提示音即可，不需要 TTS：

| 状态 | 提示音 |
|------|--------|
| `waiting` | 一段引起注意的提示音（如两声上升音）|
| `done` | 一段愉悦的成功音（如三声上升音）|
| `error` | 一段低沉的错误音（如两声下降音）|
| 其它状态 | 不发声 |

> 第一步音效可以是程序生成的简单音调（蜂鸣 / 方波），
> 不必是音频文件。重点是"有声音提醒"。

## 性能注意

- 这块板有 8MB PSRAM，跑 LVGL 矢量动画足够。
- 用 LVGL 的 animation（`lv_anim`）驱动补间，开双缓冲 + DMA。
- 目标：动画流畅无撕裂，状态切换响应迅速。
